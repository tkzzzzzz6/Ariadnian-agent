如何读这些数字

  • 训练 loss 从 3.1455 下降到 0.000746，说明小数据上的优化在运行。
  • dev loss 为 0.007150，只来自 2 条相似的合成样本。
  • 100% 是已给定正确前缀的 token 命中率，不能视为自由生成回答准确率。
  • SWIFT 日志显存 10.0723 GiB 与整卡采样是两种定义；离散采样可能漏掉尖峰。

下一阶段必须补的证据

  • 冻结训练前基线与独立公开测试集，保持 prompt、输出预算和评分协议一致。
  • 真实 4K / 8K / 16K 输入及跨段、跨文档任务；不能只把配置长度改大。
  • 短上下文训练对照、长上下文训练对照、多随机种子及置信区间。
  • 长文提升与短任务退化同时报告，保留失败和超限分母。
