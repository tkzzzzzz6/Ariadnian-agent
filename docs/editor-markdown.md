# 编辑格式与问答 Markdown

## 编辑入口

- 顶部工具栏和选中文字后的浮动工具栏共用文字格式操作：粗体、斜体、下划线、链接；「更多文字格式」提供删除线、行内代码、上下标、三种高亮和清除文字格式。清除操作保留标题、表格、公式及引用内容。
- 点击「设置链接」或 Ctrl+K，输入网页/邮件地址；空选区可填写显示文字，选区文字可添加或移除链接。编辑期间文字发生变化会要求重新选择，不覆盖后续修改。
- 顶部「插入」和段首 `/` 共用菜单：正文、H1–H3、有序/无序列表、引用块、代码块、分割线、图片、表格、行内/独立公式。支持中英文搜索和键盘操作。列表可增加或减少缩进。
- 普通粘贴自动识别支持的纯文本 Markdown；已有 HTML 格式仍使用原编辑器的粘贴流程。Ctrl+Shift+V 作为纯文本粘贴，不自动创建列表、表格或公式。
- `$公式$` 在闭合时自动生成行内公式；`$$公式$$` 自动生成独立公式，即使前后有正文或尾随空格也会保留正文并转换。三个反引号会立即进入代码块，在代码块结尾另起一行输入三个反引号并回车可回到正文。当前行已有源码未转换时，空格或回车可补触发，不必打开弹窗。旧文档的普通美元符号文本不会被自动迁移。代码中保留源码，未确认的 Agent 草稿不进行格式或块类型转换。

## 代码块语言与高亮

每个代码块顶部都有语言选择、自动换行和复制按钮。支持自动识别、纯文本以及 Python、JavaScript、TypeScript、C/C++、Java、Go、Rust、Shell/Bash、SQL、JSON、YAML、HTML/XML、CSS、Markdown；语言和换行设置随文档保存，切换语言支持撤销/重做，源码不会改变。

输入三个反引号直接进入代码块后，可在第一行输入语言名并回车（例如 python），随后输入代码；也可直接使用下拉菜单。粘贴带语言名的 Markdown 围栏会保留其语言。未注册的语言保留标签和源码，以纯文本显示。

编辑器与问答预览共用高亮规则；问答中展示围栏声明的语言，插入正文后可以继续切换。高亮通过文本节点与样式实现，不执行代码，也不将源码当作 HTML。复制仅包含源代码。

只注册上述常用语言；自动识别超过 12,000 字符、指定语言超过 40,000 字符时暂停着色并保留源码，编辑器显示提示。此阈值用于限制渲染工作量，不是性能测量结果。

Markdown 导出保留代码围栏及语言名，Word 沿用 Pandoc 对已知语言的代码处理；LaTeX 保留语言标签和原样代码，不承诺与编辑器相同的着色。

## 文献问答

回答默认预览 Markdown 标题、粗斜体、删除线、列表、引用、链接、表格、代码和数学公式。可切换「Markdown 源码」或复制原始 Markdown。流式生成约每 80 ms 更新一次预览，结束后立即显示最终内容；用户向上阅读时不强行滚回底部。这里是刷新节流策略，不是延迟或性能实测结果。

回答中的有效来源编号可以定位来源卡片，点击卡片查看文献。相同论文的不同证据编号各自保留；未知编号保留原文，不编造成有效引用。代码、公式和真实链接中的数字不解释为来源编号。

「插入到正文（带引用）」将回答转成可编辑的标题、列表、表格、代码与公式，而不是粘贴带 Markdown 符号的单段文本。引用只使用当前文献库仍存在的来源；整个插入支持一次撤销/重做。请将光标放在普通正文位置。未原生支持的脚注保留为注释标记及注释文本。

预览不执行原始 HTML，不加载外部图片，不允许可执行链接；外部图片保留文字说明。本地图片仍通过现有上传入口管理。生成中断时保留已经收到的内容并提示，不将部分回答标作完整回答。

## 保存与导出

新格式沿用文档 JSON，无需迁移旧文档。Word 中保留下划线、删除线、上下标、超链接和原生字符底色。LaTeX 使用对应命令、`xcolor` 和 `ulem`；Markdown 资源包使用 Pandoc Markdown，包含下划线及高亮属性，普通 GFM 阅读器可能不能显示这些扩展样式。内置高亮支持黄、绿、蓝三种；不保证与所有 Word/WPS 客户端的显示完全一致。

## 验证与范围

- 后端 131 项离线测试通过，覆盖新增格式 Word 结构、链接限制及原有图表公式导出。
- 前端 62 项检查通过，覆盖 Markdown 结构转换、真实/未知来源、同论文多证据编号、代码/公式保护、保存数据和导出序列化；以本分支实际测试输出为准。
- Edge 浏览器验证选区格式、链接校验、代码块菜单、清除格式及撤销、保存刷新、Markdown/纯文本粘贴、受控 SSE 回答预览、来源跳转、结构化插入和实际 Word/LaTeX 下载。实际 LaTeX 包使用 XeLaTeX 且禁用 shell escape 编译。
- 浏览器问答使用受控模拟响应与独立离线数据，没有付费模型调用，不能据此判断真实回答质量。现有主界面的手机分栏布局仍需单独适配；本次桌面流程已验收，新浮窗限制在视口内。

本次为编辑改进的第一批，同时包含此前的美元符号公式快捷输入。提示块、待办、块拖动、标题折叠、版本快照和多人实时协作仍属后续需求。
