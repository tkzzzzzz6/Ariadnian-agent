## 首期产品口径

- 阅读状态是用户主动确认的 `unknown`（未记录）、`unread`（未读）、`reading`（阅读中）、`read`（已读）。状态属于当前本地文献库，不属于某一文档；首期沿用现有单用户边界。
- 可记录、修正读至页码和总页数。页码为空表示未知；页码以 PDF 物理页序号计数。阅读器提供“记录当前页”，由用户确认读至该页；打开、滚动、跳转到最后一页均不自动认定已读。不把页数比率称为理解程度。
- 读至页码可以回退；用户标为未读或未记录时清空页码。已读也允许总页数未知，适用于外部阅读或无本地 PDF 的文献。更换 PDF 后不自动重写用户记录，须人工复核页码。
- 笔记数是该文献全部 notes 行数（包含只有划线的条目），不是评论文字数量；随现有笔记 store 更新，加载失败显示未知。
- 引用次数只针对当前打开文档的内存内容，包含 Agent 草稿；每个 citation 节点对其中每篇文献计一次，同节点重复 id 只计一次。纯文字作者年份、参考文献表、其他文档不计数。随编辑器事务更新，包括未保存编辑与撤销/重做；重新打开以持久化文档为准。
- 当前文档至少引用 2 次且未确认已读时提醒。区分“未记录阅读”“明确未读”“尚未确认读完”，不推断用户实际未阅读。提示出现在对应文献条目，可打开阅读记录或原文。
- 临时在线 PDF 预览不建立库内阅读记录；缺少 PDF/老数据默认未知，不补造阅读进度。首次运行只新增表，不改变旧文档和笔记。

## 实现边界

- 新增 SQLite paper_reading 表（paper_id 主键、status、read_through_page、total_pages、updated_at），文献删除级联；GET /api/reading 返回库内文献记录（无行时返回未知），PATCH /api/reading/{paper_id} 校验并保存。修改不触发模型调用。
- 文献库展示状态、划线/笔记数、当前文档引用次数、提醒；阅读记录弹窗支持状态和页码修正；原文面板共享该入口，并可记录当前页；有记录时可主动继续阅读。
- 不实现阅读时长、自动已读推断、章节级完成率、全库文档引用排行、账号隔离和跨设备实时同步。不同浏览器需重新载入才能看到对方变更。

## 验收方案

| 场景 | 预期 |
|---|---|
| 旧库首次升级、文献无 PDF | 未记录，页码未知；原有文档/笔记不变 |
| 修改状态/页码，重新请求、刷新、重开 | 恢复已保存值；失败提示且不虚报保存成功 |
| 打开 PDF、滚动或定位依据 | 不修改持久化阅读状态 |
| 点击记录当前页 | 用户确认阅读中及该页/总页数；已确认已读保持已读 |
| 手工回退页码、清空页码、改为未读 | 正确保存；未读/未记录清空读至页码 |
| 非法状态、负数/小数页码、页码超总页数 | API 拒绝，原记录不变 |
| 仅划线、加评论、删除笔记 | 数量以 notes 行数为准；加载失败显示未知 |
| 同节点多篇/重复 id、重复引用节点 | 按文献的节点次数计数，同节点去重 |
| 插入/删除引用、撤销/重做、切换文档 | 当前文档统计即时更新，不混入其他文档 |
| 引用次数 1→2、状态未知/未读/阅读中/已读 | 提醒阈值与文案匹配；已读无提醒 |
| 删除文献 | 阅读记录级联删除；重加文献不复用旧记录 |

后端使用隔离临时库测试 API、数据库重连和旧库升级；前端使用真实 ProseMirror 事务与 history 验证计数、撤销/重做及提醒规则；完成 TypeScript 检查、现有回归与生产构建。浏览器手工/自动验收结果单独记录，不将纯逻辑测试当成 UI 验证。
