# 图片、表格与公式（Issue #3）

## 使用方法

- 点击编辑器顶部的「插入」，或在普通段落开头输入 `/`，搜索图片、表格、行内公式或独立公式。支持方向键选择、Enter 确认、Esc 关闭。
- 图片支持上传、粘贴截图和拖入 PNG/JPEG。上传成功后插入；选择图片可调整宽度、修改图题和替代说明、替换或删除。双击图片也可打开编辑窗口。
- 表格默认 3×3，可配置第一行为表头。在表格内使用上下文操作增删行列、切换表头；Tab 切换单元格。规则 TSV/Excel 数据粘贴到普通正文时创建表格，粘贴到现有单元格时覆盖相应矩形，必要时扩展表格。
- 公式弹窗提供 LaTeX 源码、实时预览和分数/求和/积分/矩阵模板。点击公式重新编辑；Ctrl+Enter 确认弹窗。源码存入文档，而不是存成截图。
- 公式快捷输入：正文键入 `$x^2$`，输入最后一个 `$` 后转换为行内公式；键入 `$$\frac{a}{b}$$` 转为独立公式，前后正文会保留；空格或回车也可补触发当前行的公式源码。输入 `$$$$` 本身没有公式内容，不会转换。
- 纯文本粘贴支持混排 `$...$`、`$$...$$`，以及多行 `$$` 分隔的独立公式。带格式内容按原有 HTML 粘贴规则保留；普通粘贴自动识别支持的 Markdown；Ctrl+Shift+V 保留为纯文本，不转换公式或列表。独立公式不能放进表格单元格，单元格内可键入行内公式。
- 快捷输入跳过代码块、行内代码和未确认的 Agent 草稿；反斜杠转义的美元符号、未闭合或无效公式保留为文本。不会扫描并转换旧文档或 Agent 写入的普通美元符号文本。公式转换支持撤销/重做、保存与原有导出。
- 每次插入和弹窗修改作为独立编辑步骤参与撤销/重做。原有 `@` 引用入口保留。

更多文字格式、统一菜单和问答 Markdown 预览见 [编辑与问答使用说明](editor-markdown.md)。

## 资源与兼容性

文档仍以 Tiptap JSON 保存在 `documents.content`。新增 `image`、`table/tableRow/tableCell/tableHeader`、`inlineMath/blockMath` 节点，不对旧文档中的 `$...$` 普通文字进行自动转换。

图片元数据存入 `document_assets`，文件位于数据目录的 `images/`。每张图片属于一篇文档，同一篇文档重复上传相同字节会复用资源。文档仅保存资源 ID 与显示属性；图片服务使用现有访问密码中间件。上传检查真实格式、解码结果、文件大小和像素数。导出只读取本项目管理的图片资源，不下载外部图片或接受任意本地路径。

删除图片节点不会立即删除图片文件，保证撤销可以恢复。首期不提供自动删除未引用图片的回收功能；备份时应同时备份数据库与 `images/`，不能只复制文档 JSON。

选区包含图表/公式时，不直接进行 AI 整体改写；自动页边润色和续写跳过表格及包含公式的段落。普通正文仍正常处理。Agent 的文本上下文保留公式源码、表格行列和图片说明；不自动发送图片给视觉模型。更新、保留或删除 Agent 草稿时，保留用户自己的图表与公式。

## 导出

- Word：继续使用 Pandoc 和现有 CSL 引用排版。图片嵌入文件；表格为原生 Word 表格；可转换的公式输出 OMML，可在 Word 中编辑。无法转换的公式明确报错，避免静默退化。前端 Blob 请求与直接附件请求分别设置响应头，并检查空文件。
- LaTeX：下载 ZIP，包含 `main.tex`、`refs.bib`、`images/` 与说明文件。中文使用 `ctexart`，推荐 XeLaTeX；有引用时再执行 BibTeX。图片按正文位置输出；表格使用 `longtable`；公式保留源码。
- Markdown：下载同样带图片和参考文献的 ZIP，采用 Pandoc Markdown。规则表格、公式和资源路径保留。

## 第一版边界

- 图片：PNG/JPEG，最多 10 MB/张且服从部署的更小上传限制；最多 2500 万像素。外链、SVG、裁剪和文字环绕暂不支持。导出最多 200 张、图片总大小不超过 100 MB。
- 表格：最多 50 行、10 列；单元格支持段落、基本文字格式、引用、行内公式。合并单元格、嵌套表格、单元格图片、计算公式与 Excel 复杂格式不支持。粘贴应为规则 TSV，不解析带嵌入制表符/换行的 CSV 引号规则。
- 公式：KaTeX 支持的数学语法，源码最多 8000 字符；不支持文件读取、自定义宏和外部资源命令。自动公式编号、交叉引用、数学正确性验证不在本期范围。表格内带竖线列布局的 `array` 公式需改为普通矩阵再导出 Word。
- Word、LaTeX 和编辑器保持内容与顺序，不保证字体、分页、列宽完全一致；Word/WPS 各客户端仍需要人工检查版式。

## 并行开发时启动

在本 worktree 根目录执行，使用独立端口，数据默认也在本 worktree 的 `backend/data/`：

```powershell
$env:ARIA_API_PORT = '8033'
$env:ARIA_WEB_PORT = '5176'
npm run demo
```

打开 `http://localhost:5176`。演示模式不调用模型；真实模型体验使用 `npm run dev` 并单独配置本 worktree。以上环境变量只影响当前终端。
