# 独立公开长上下文基准实测：2026-11-05

本轮使用外部官方题目和参考答案，完成 **132 次真实模型请求**，全部返回非空、可评分文本；这不表示全部答对。没有训练或 CPT，也没有重新构造参考答案。自建语料诊断仍单独记录在[原实测报告](long-context-data-results-20261105.md)。

模型为现有配置中的 `openai/deepseek-flash`，服务返回模型名 `deepseek-flash`；`thinking=disabled`、`temperature=0`，每题最多一次请求，超时 60 秒，无重试和备用模型。完整原文运行 42 题，三种 8K 预算策略各运行同一组 30 道 v1 题。调用后没有换题或挑选重跑。

## 来源、选样与协议

来源是 [LongBench v1](https://huggingface.co/datasets/zai-org/LongBench) 和 [LongBench v2](https://huggingface.co/datasets/zai-org/LongBench-v2)，官方提示词和评分代码固定在 [THUDM/LongBench 的指定版本](https://github.com/THUDM/LongBench/tree/2e00731f8d0bff23dc4325161044d0ed8af94c1e)。原始数据、任务、参考答案、逐条预测留在本机；小型来源与结果清单可以版本化。

v1 所选六项任务原有 1,200 题，均通过长度资格；v2 原有 503 题，184 题符合资格，319 题在推理前排除。v2 各领域符合资格的数量依次为：代码仓库 6、长样例学习 13、长结构数据 2、长对话历史 20、多文档问答 66、单文档问答 77。因此这是一组**长度筛选后的固定小子集**，不是整个 v2 的均匀随机样本。所选 v1 原文为 1,963–16,799 个参考 token，v2 为 9,975–58,339。

参考 tokenizer 及其散列见清单；它只用于跨策略预算，不等于服务商原生 token。预算不包括问题、指令和聊天模板。完整原文运行没有隐式截断；8K 实验则明确更换了输入上下文，不能并入完整原文成绩。

使用官方任务模板、生成长度上限和评分实现，未附加引用 JSON 或额外系统提示；gold 仅用于评分。v2 采用官方 non-CoT 模板与严格答案提取，但本轮统一温度为 0，固定版本上游 non-CoT 代码温度为 0.1，因而不声称完全复现官方推理配置或排行榜。

## v1：相同 30 题的四种输入方式

分数均为百分制。每项只有 5 题；F1、ROUGE-L 和准确率的含义不同。最后一行只作本轮六任务等权描述，不能解释为统一的答案正确率。

| 任务与指标 | 完整原文 | 8K BM25 | 8K 章节标题加权 | 8K 顺序截断 |
|---|---:|---:|---:|---:|
| Qasper：论文问答 F1 | 61.71 | 59.08 | 61.71 | 61.33 |
| HotpotQA：多文档问答 F1 | 49.33 | 56.00 | 49.33 | 58.86 |
| MultiFieldQA-zh：中文问答 F1 | 73.33 | 73.33 | 73.33 | 73.33 |
| GovReport：摘要 ROUGE-L | 31.79 | 31.82 | 32.64 | 30.77 |
| TREC：分类得分 | 0.00 | 20.00 | 20.00 | 0.00 |
| Passage Retrieval-en：段落检索得分 | 100.00 | 100.00 | 100.00 | 60.00 |
| 六任务等权均值 | 52.70 | 56.71 | 56.17 | 47.38 |

本轮检索题中 BM25 与标题加权保住了 5/5 的目标段落得分，顺序截断为 3/5；说明本轮存在位于截断范围外、需要选择的内容。这个小样本不支持总体显著性或稳定提升结论。

**BM25 与章节标题加权的 30/30 份实际上下文完全相同。** 两轮仅有 18/30 份预测字符串相同，服务即使在温度 0 下也没有表现为逐字确定。它们的分数差异应视为重复推理波动，不能归因于结构权重。现有标题识别在此子集未产生可验证的输入变化，是后续改进和扩大样本需要面对的负结果。

TREC 完整原文的 5 题全部得 0。检查发现模型常先解释、再在后续行写分类标签，而官方实现只评分第一行；其中一题还触及 64 token 官方输出上限。本轮保留原始预测及官方评分，没有事后抽取末行标签来抬分。这个结果暴露了格式遵循问题，不能简单解释为模型完全不懂分类。

## v2：完整原文的六类场景

使用官方严格选项提取，正确 5/12，准确率 **41.67%**。每个领域只有两题，单题就会改变 50 个百分点。

| 官方领域 | 正确 / 题数 | 准确率 |
|---|---:|---:|
| Code Repository Understanding | 0 / 2 | 0% |
| Long In-context Learning | 1 / 2 | 50% |
| Long Structured Data Understanding | 1 / 2 | 50% |
| Long-dialogue History Understanding | 0 / 2 | 0% |
| Multi-Document QA | 2 / 2 | 100% |
| Single-Document QA | 1 / 2 | 50% |

没有把 v2 选项准确率与 v1 六种任务混算成一个总分。这里也没有外部证据跨度真值，因此不虚构证据召回率。

## 用量与核验

| 运行 | 请求数 | 输入 token | 输出 token | 以 length 结束 |
|---|---:|---:|---:|---:|
| 完整原文 | 42 | 580,650 | 3,482 | 9 |
| 8K BM25 | 30 | 182,730 | 2,856 | 6 |
| 8K 章节标题加权 | 30 | 182,730 | 2,853 | 5 |
| 8K 顺序截断 | 30 | 182,532 | 2,814 | 6 |
| 合计 | 132 | 1,128,642 | 12,005 | 26 |

以上为服务商返回的实际用量，合计 1,140,647 token。费用未返回且无本轮已核验计价，记为 `null`。`length` 表示触及官方任务生成上限，非空答案仍按官方方法评分，不能把它描述为未截断的完整生成。没有失败、跳过或空答案；可评分覆盖率为 100%，与正确率不同。

逐条离线重新评分与保存的分数一致；各策略使用同一冻结 ID 顺序，8K 实际选中文本均满足参考预算，四轮实现快照一致，来源散列正确。以空白归一化后的整篇文本比对，本轮 42 个公共 context 与本地 493 篇原始文档、350 篇筛后文档均无整篇精确重合；这不排除片段重合、语义相似或基座预训练污染。

评测后又收紧了 CLI 的输入检查并修正文档路径，未重新请求模型；运行时实现散列保留在每轮 summary 中。结果描述以当时的固定输入、参数及预测为准。

最终后端完整测试 **280 项通过**，依赖锁与 npm 入口检查通过；新规则对 42 条实际输入的来源、提示词和选样清单校验也已通过。本地数据未删除，原始记录与逐条预测的忽略规则已逐路径核验。
